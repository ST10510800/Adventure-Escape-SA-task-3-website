# Adventure Escape SA 🌍

A responsive web application and digital platform built for **Adventure Escape SA**—an eco-tourism and outdoor adventure SME offering guided tours, hiking, kayaking, and custom booking experiences.

## 🚀 Project Overview
This project was designed and built to fulfill academic and commercial requirements for a full-featured web presence. It features clean, side-by-side flexbox layouts, interactive forms, fee calculators, and detailed individual activity pages matching professional Figma wireframes.

## 🛠️ Tech Stack
* **HTML5** (Semantic structure)
* **CSS3** (Custom global stylesheet, Flexbox-based layouts, and responsive design)
* **JavaScript** (Form validation, fee calculation scripts, and interactive components)
